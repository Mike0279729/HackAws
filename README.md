# HackAws

Aplicación web simple para facilitar el acceso a servicios de salud:

- Localiza hospitales y centros de salud cercanos.
- Consulta disponibilidad de medicamentos.
- Compara precios de consultas y estudios.
- Encuentra citas médicas disponibles.

## Ejecutar

No requiere instalación. Abre el archivo `/home/runner/work/HackAws/HackAws/index.html` en un navegador.
